حول المشروع

اسم المشروع: موقع تعريفي لهجمة الزيرو داي بشكل متقدم مع محاكاة تعليمية.

الهدف: توفير مصدر عربي منظم يشرح مفهوم الزيرو داي، يربطه بأمثلة موثقة، ويعرض محاكاة بصرية آمنة دون أي استغلال حقيقي.

الجمهور المستهدف: طلاب كليات الحاسوب والأمن السيبراني، والمهتمون بالتوعية التقنية.

المنهجية

  • تحليل مصطلحات الأمن وربطها بأحداث حقيقية مُختارة بعناية.
  • تصميم قاعدة بيانات SQLite لتغذية واجهة ديناميكية.
  • بناء واجهة RTL بخط محلي واحد ومتسق.
  • محاكاة أمامية فقط مع تسجيل خطوات التعلم في الخادم.

التقنيات المستخدمة

HTML + SVG

هيكل عربي RTL وأيقونات متجهية مضمّنة دون صور خارجية.

CSS

سمة داكنة موحّدة، شبكات تفاعلية، وبطاقات بظلال خفيفة.

JavaScript

تفاعل مع REST، عدّ رسومي للإحصائيات، وتبويبات ومسارات تقدم.

Python / Flask

خادم خفيف يقدّم القوالب وواجهات JSON للبيانات الحية.

SQLite

تخزين الثغرات، الجدول الزمني، الاختبارات وسجل المحاكاة.

مصادر ومراجع أكاديمية ومفتوحة

  • MITRE ATT&CK — إطار سلوك الخصوم.
  • CVE Program — معرّفات الثغرات.
  • CVSS — منهجية تقييم الخطورة.
  • NVD — تفاصيل وثائقية للثغرات.

معلومات المطوّر

مشروع تخرج — يمكنك استبدال هذا السطر باسم الطالب، الرقم الجامعي، والإشراف الأكاديمي.
